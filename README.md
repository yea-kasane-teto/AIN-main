# AIN — AI에 들어가다

AI를 처음 만나는 학습자가 기초 개념부터 직접 탐색하도록 돕는 인터랙티브 교육 웹사이트입니다.

## 현재 구현

- F-01 학습 로드맵 홈 화면
- 기초, 수학, 머신러닝, 딥러닝, 대표 모델, 심화 학습 영역
- 학습 영역 필터와 단원 통합 검색
- 접고 펼칠 수 있는 사이드바
- 모바일과 데스크톱 반응형 레이아웃
- 팀 연락처가 포함된 footer

## 실행

`index.html`을 정적 웹 서버로 열면 됩니다. ES modules를 사용하므로 브라우저에서 직접 파일을 열기보다 Live Server 같은 로컬 서버를 권장합니다.

## 구조

```text
AIN/
├── assets/                 # 로고 등 정적 자산
├── index.html              # F-01 홈 화면 마크업
└── src/
    ├── components/         # 로드맵 카드와 필터 UI
    ├── data/               # 학습 영역 및 차시 데이터
    ├── modules/             # 검색, 내비게이션 등 동작
    ├── styles/              # 반응형 디자인 시스템
    └── main.js              # 화면 조립과 상태 관리
```

학습 영역 데이터는 `src/data/roadmap.js`에서 관리합니다. 이후 각 영역을 `base-01`, `math-01` 같은 차시 모듈로 확장하고, 각 차시의 이론·수식·시각화 모듈을 서로 분리할 수 있도록 구성했습니다.
